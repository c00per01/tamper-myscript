### 📚 БАЗА ЗНАНИЙ: ЯНДЕКС.ДИРЕКТ (НЕУКОСНИТЕЛЬНОЕ СОБЛЮДЕНИЕ)
Любой код, работающий с текстом запросов, обязан соблюдать эти правила. Нарушение этих правил делает скрипт бесполезным.

1. **"!" (Восклицательный знак) — Священен.**
   - Фиксирует словоформу (число, падеж).
   - *Задача:* При очистке/нормализации текста НИКОГДА не удалять "!" перед словом. Если юзер ввел `!купить`, скрипт обязан сохранить `!купить`.

2. **"+" (Плюс) — Священен.**
   - Фиксирует предлоги/стоп-слова.
   - *Задача:* При очистке НИКОГДА не удалять "+" перед словом. `+как` должно остаться `+как`.

3. **Логика Минус-Фраз:**
   - Скрипт должен понимать, что минус-фраза может состоять из нескольких слов (через пробел). Нельзя разбивать фразу на отдельные слова при сохранении, если это единая сущность.

4. **Безопасность данных:**
   - Мы делаем инструмент для профи. Ошибочное удаление нужного минус-слова недопустимо. Лучше сохранить лишнее, чем удалить важное (спецсимволы).
