# Yandex Direct Helper

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-ISC-green)

**Профессиональный инструмент для быстрой работы с минус-фразами в Яндекс.Директ**

Расширение для браузера, которое превращает рутинную работу по очистке поисковых запросов в быстрый визуальный процесс.

## 🚀 Основные возможности

- **Умное выделение слов:** Клик по слову мгновенно выделяет его во всей таблице с учётом словоформ
- **Построение фраз:** Двойной клик позволяет собирать минус-фразы из нескольких слов
- **Визуальная подсветка:** Все выбранные слова подсвечиваются в реальном времени
- **Автоматическая пакетная отправка:** Скрипт сам разбивает список на пакеты и отправляет их
- **Типы соответствия:** Поддержка кавычек, квадратных скобок, операторов + и !
- **Авторедирект:** Автоматическая настройка правильных параметров отчёта
- **История отправок:** Отображение даты последней очистки минус-фраз

### Ручная установка (для разработчиков)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/c00per01/tamper-myscript.git
cd tamper-myscript
```

2. Установите зависимости и соберите расширение:
```bash
npm install
node build-for-store.js
```

3. Загрузите в Chrome:
   - Откройте `chrome://extensions/`
   - Включите "Режим разработчика"
   - Нажмите "Загрузить распакованное"
   - Выберите папку с проектом

## 🎯 Как использовать

1. Перейдите в отчёт "Поисковые запросы" в Яндекс.Директе
2. Кликайте по ненужным словам — они будут подсвечиваться
3. Используйте кнопки в панели для изменения типа соответствия
4. Нажмите "Отправить" — расширение само разобьёт на пакеты и отправит

## 🛡️ Конфиденциальность

Расширение **не собирает и не передаёт никакие данные**. Все настройки и выбранные фразы хранятся только локально в вашем браузере.

Подробнее: [Политика конфиденциальности](PRIVACY_POLICY.md)

## 🔧 Для разработчиков

### Структура проекта

```
tamper-myscript/
├── myscript.user.js        # Исходный код (совместим с Tampermonkey)
├── content.js              # Собранная версия для расширения
├── manifest.json           # Manifest V3
├── icons/                  # Иконки расширения
├── _locales/              # Локализация (ru, en)
├── build-for-store.js     # Скрипт сборки ZIP для магазинов
└── dist/                  # Готовые архивы для публикации
```

### Команды сборки

```bash
# Собрать расширение и создать ZIP
node build-for-store.js

# Только создать content.js (без Tampermonkey заголовков)
node build-extension.js

# Создать иконки из исходного изображения
node generate-icons.js
```
