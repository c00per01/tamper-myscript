# Проект: Yandex Direct Search Queries - Userscript для работы с минус-словами

## 📋 Основные требования

### Функциональность
1. **Выделение слов** в поисковых запросах Яндекс.Директа
   - Мягкое выделение (по основе слова) - обычный клик
   - Строгое выделение (точная словоформа) - Alt+клик
   - Фразовое выделение (несколько слов) - двойной клик + клики по другим словам
   - Автоматическое переключение в строгий режим для стоп-слов

2. **Управление чекбоксами строк**
   - Автоматическая активация чекбокса при выделении слова
   - Чекбокс должен оставаться активным, пока хотя бы одно слово выделено
   - Чекбокс снимается только когда в строке нет выделенных слов

3. **Отправка минус-слов**
   - Резервирование строк (автоматическая установка чекбоксов)
   - Взаимодействие с модальным окном Яндекс.Директа
   - Выбор "на кампанию" в выпадающих списках
   - Заполнение полей ввода
   - Автоматическое закрытие попапа результата

4. **Панель управления**
   - Отображение выделенных слов/фраз
   - История отправленных минус-слов
   - Импорт минус-слов из буфера обмена
   - Редактирование типа соответствия (обычное/фразовое/точное)
   - Inline-редактирование текста минус-слов
   - Кнопки "Отправить" и "Очистить всё"

5. **Визуальные маркеры**
   - Подсветка выделенных слов
   - Подсветка слов из истории отправки
   - Подсветка импортированных минус-слов
   - Подсветка слов, уже находящихся в кампании
   - Режим построения фразы (голубая подсветка, деактивация других строк)

## 🎯 Ключевые технические решения

### 1. Обработка событий
**Проблема:** Клики на слова вызывали toggle чекбокса строки в Яндекс.Директе
**Решение:** 
- Прямое навешивание listeners на каждый `<span>` (не делегирование)
- `e.stopPropagation()` на `click`, `mousedown`, `mouseup`
- Delayed double-check в `ensureRowChecked()` для устранения race conditions

### 2. Динамическое обновление таблицы
**Проблема:** Яндекс перерисовывает строки, уничтожая наши spans
**Решение:**
- `MutationObserver` на tbody таблицы
- Автоматическое перезаворачивание слов при изменениях
- Проверка на существующие `.yd-word` для предотвращения дублирования
- `cleanWordSpans()` для удаления detached элементов

### 3. Логика отправки (из Малый код.txt)
**Особенности:**
- Валидация и предупреждения о неназначенных элементах
- Поиск свободных строк (`findFreeRows`)
- Программное нажатие чекбоксов (`clickCheckbox`)
- Ожидание модального окна с таймаутами
- Заполнение полей 1-к-1 (не объединение в одно поле)
- Сохранение истории и импортированных минус-слов

### 4. Стемминг и сопоставление
- Реализация Porter Stemmer для русского языка
- Мягкое сопоставление по основе слова
- Строгое сопоставление по точной форме
- Фразовое сопоставление (набор слов, порядок не важен)

## ⚠️ Важные нюансы

### Правила Яндекс.Директа (НЕУКОСНИТЕЛЬНОЕ СОБЛЮДЕНИЕ)
1. **"!" (восклицательный знак)** - фиксирует словоформу
   - При очистке/нормализации НИКОГДА не удалять
   - `!купить` должно остаться `!купить`

2. **"+" (плюс)** - фиксирует предлоги/стоп-слова
   - При очистке НИКОГДА не удалять
   - `+как` должно остаться `+как`

3. **Минус-фразы** могут состоять из нескольких слов
   - Нельзя разбивать на отдельные слова при сохранении

### Особенности реализации
1. **Стоп-слова** автоматически переключаются в строгий режим
2. **Фраза из 2 слов** автоматически завершается при выборе второго слова
3. **Любая клавиша** завершает режим построения фразы
4. **Клик вне слов** также завершает режим фразы
5. **Клик по уже выбранному слову** в режиме фразы отменяет всю фразу

### CSS стили
- "Apple-like" дизайн из Малый код.txt
- Кнопка "Отправить" больше (flex: 2)
- Кнопка "Очистить всё" меньше (flex: 1)
- Удалены кнопки Undo/Redo
